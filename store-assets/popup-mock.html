Add a skip rule

How it works

  1. Click "Select the button to skip".
  2. Click the button on the page (e.g. the Skip Intro button).
  3. We auto-detect the most reliable match and save the rule for you — or, if "Choose match manually" below is on, show every match so you can pick.

Advanced: enter manually

When you need this

Only if the picker above can't find the button, or you want to fine-tune the match. Right-click the button on the page → Inspect to find its attributes.

Help

Adding a rule automatically

  1. Go to Add Rule and click Select the button to skip.
  2. On the page, click the button you want auto-skipped (e.g. Skip Intro).
  3. By default we detect the most reliable match and save the rule right away — reopen the popup to see a confirmation and any alternative matches.

Choosing the match yourself

Open Advanced: enter manually in Add Rule and turn on Choose match manually. Step 3 above then changes: instead of auto-saving, we show every match found on the page so you can pick the one you want.

Match types

Entering a rule manually

If the picker can't find the button, open Advanced: enter manually and fill in the site, a label, a match type, and the value to match. Right-click the button on the page → Inspect to find its attributes.

Managing rules

Use the checkbox on a rule to enable or disable it, the pencil icon to rename it, Edit details to change its match, or Delete to remove it.
